# Анализ эмиссии банковских карт

## Цель проекта

Изучить динамику выпуска банковских карт, выявить особенности распределения эмиссии между филиалами, сопоставить объём выпуска с количеством активных карт и оценить выполнение плана выдачи.

## Задачи проекта

- Подготовить исходные данные и привести наименования карточных продуктов к единой классификации.
- Проанализировать динамику выпуска карт в течение года.
- Определить вклад филиалов в общий объём выпуска с помощью диаграммы Парето.
- Сопоставить распределение выпуска и активности карт с помощью ABC-анализа.
- Сравнить плановые и фактические показатели выдачи и определить периоды наибольших отклонений.

## Данные
В основе проекта использованы данные карточного портфеля банка. Для публикации в открытом доступе числовые показатели были изменены и не соответствуют фактическим значениям.

Персональные данные клиентов и сотрудников не используются.

## Результаты анализа

### 1. Динамика выпуска карт

Выпуск менялся неравномерно в течение года. С января по март он вырос с 29 439 до 43 550 карт — примерно на 48%. После мартовского максимума объём выпуска снизился, а к декабрю восстановился до 37 052 карт.

При этом декабрьский результат оказался примерно на 15% ниже мартовского максимума. Таким образом, март стал пиковым месяцем выпуска, но достигнутый объём не сохранялся на протяжении года.

### 2. Концентрация выпуска по филиалам

Пять крупнейших филиалов обеспечили 47,2% общего выпуска, а одиннадцать из восемнадцати — 80,2%. Следовательно, основная часть эмиссии сосредоточена примерно в 61% филиалов.

Кадамжайский филиал занимает первое место с результатом 47 176 карт (10,8% выпуска). При этом на него приходится лишь около одной десятой общего объёма, то есть выпуск распределён между несколькими крупными филиалами, а не определяется одним лидером.

Диаграмма Парето позволяет выделить группу филиалов, формирующих основную часть эмиссии, и сократить число объектов для последующего углублённого анализа.

### 3. Сопоставление выпуска и активности карт

Сравнение ABC-сегментов показывает, что высокий объём выпуска не всегда сопровождается аналогичной позицией по количеству активных карт.

- **Балыкчинский филиал — AB:** сегмент A по выпуску и B по активности. Филиал входит в группу, формирующую основную часть выпуска, но по активности уступает лидирующему сегменту.
- **Нарынский филиал — BC:** сегмент B по выпуску и C по активности. Его позиция по активности заметно ниже позиции по выпуску.
- **Филиал «Раззаков» — CB:** сегмент C по выпуску и B по активности. Несмотря на сравнительно небольшой объём выпуска, филиал занимает более высокую позицию по количеству активных карт.

Эти различия помогают выделить филиалы для дальнейшего изучения. В частности, стоит проверить, связаны ли расхождения с долей неактивных карт, сроками с момента выпуска или особенностями клиентской базы.

### 4. Выполнение плана выдачи

План выполнен или перевыполнен в 6 из 12 месяцев. При этом результаты заметно различались в течение года.

В марте фактическая выдача составила 46 168 карт при плане 35 592 — выполнение достигло 130%. В ноябре и декабре, напротив, выполнение составило 76% и 77%. В декабре при наиболее высоком месячном плане — 47 117 карт — фактически выдано 36 439 карт.

Таким образом, высокий план не всегда сопровождался соответствующим объёмом фактической выдачи. Это позволяет выделить конец года для отдельного анализа: необходимо проверить обоснованность плановых значений и причины отклонений факта от плана.
